# raccoon create (removed)

`raccoon create project` and `raccoon create mission` no longer exist.

- **New project:** run the setup script of [raccoon-example](https://github.com/htl-stp-ecer/raccoon-example) — see [Creating a Project]({{< ref "/02-programming/01-project-structure#creating-a-project" >}}). A project is a git repository; the CLI is used from inside the project's own environment.
- **New mission:** `raccoon missions create M010DriveToPole` — see [raccoon missions]({{< ref "21-missions" >}}).
